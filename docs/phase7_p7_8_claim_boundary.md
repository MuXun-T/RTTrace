# Phase 7 P7.8 Claim Boundary

P7.8 supports only these claims:

- The approved P7.1-P7.7 scope has independent frozen evidence.
- Declared external packages and traces can be reopened, replayed, and
  validated in layers under their frozen contracts.
- P7.6 provides limited performance observations for the specified host.
- P7.7 provides capability/comparability evidence and remains
  `not_evaluated` for quantitative baselines.
- Phase 7 artifacts, tests, hashes, and recorded risks can be reproduced and
  audited from a clean checkout.

This closeout does not claim proof correctness, RTOS generalization,
diagnosis/root-cause accuracy, anomaly-detection SOTA, real-hardware
acquisition overhead, baseline-tool ranking, human usability, remediation
safety, or publication acceptance. P6 `reference_only`, P7 replay/validation
states, P7.6 accepted governance deviation, and P7.7 capability-only status
remain unchanged.
