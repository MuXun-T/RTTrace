2. 固定 Linux 与 Windows 两套执行环境。
3. 固定正式证据输出目录、合同版本、命令模板。

1. 选择非 repo 生成、非 padded seed 的外部稠密 trace。
2. 记录输入来源、生成/采集方式、授权边界、不可变存放路径。
3. 计算输入 SHA-256，并确认 `trace_size_bytes >= 1073741824`。
4. 在 Linux 与 Windows 上分别记录 OS、CPU、内存、Python 版本、依赖版本、仓库提交或归档版本、执行用户、时间戳。

完成判据：

## 4. 工作项 WP-01：正式输入资格确认

要做什么：

确认本轮 `10.4` 正式证明使用的 trace 满足 `real_external_dense_1gb` 条件，并且不会被判定为 prevalidation-only 或 perf-only。

怎么做：

1. 记录 trace 原始路径、来源、采集时间、采集工具、输入类型。
2. 计算 SHA-256：

```bash
sha256sum <TRACE_1GB>
```

3. 记录文件大小：

```bash
python3 - <<'PY'
from pathlib import Path
p = Path("<TRACE_1GB>")
print(p.stat().st_size)
PY
```

4. 判断是否满足 `trace_size_bytes >= 1073741824`。
5. 检查该输入不是 `public_rtos_seeded_padded` 或其他 repo-controlled padded 样本。
6. 生成 `input_qualification_report.json`。

还差哪些东西：

1. Linux 侧输入资格已完成并 `pass`：`realization/docs/evidence_proof_archive_20260418/formal_10_4/preparation/input_qualification_report.json`。
2. 当前无 Linux 侧输入资格缺口；Windows formal 启动时需复用同一 `trace_sha256` / `trace_size_bytes` 合同，并在 Windows 环境摘要中引用。

完成判据：

1. `input_qualification_report.json` 明确给出 `pass`。
2. 每个正式证据记录都引用同一份输入资格报告。
3. 若输入不满足资格，本轮结果只能标记为 supporting evidence。

## 5. 工作项 WP-02：A 组控制面先行证明

要做什么：

证明 sidecar 把重复导出从物理扫描主导转为控制面遍历主导。核心不是证明“能跑”，而是证明 evidence 主路径相对 legacy/clipped 路径显著缩小物理扫描范围，且 proof bundle 保持可验证。

怎么做：

1. 在正式输入上执行基线路径，生成 legacy/clipped 或等价全量/裁剪导出的对照报告。
2. 生成 sidecar：

```bash
cd realization
PYTHONPATH=. python3 -m desktop.app.cli sidecar-build \
  --input <TRACE_1GB> \
  --output-dir <A_OUT>/sidecar \
  --rule-family ref_ref
```

3. 使用 sidecar 执行 Mode-B 主实施例：

```bash
cd realization
PYTHONPATH=. python3 -m desktop.app.cli export-evidence \
  --input <TRACE_1GB> \
  --output-dir <A_OUT>/packages/run_001 \
  --embodiment-mode mode_b \
  --sidecar-source <A_OUT>/sidecar/control/dependency_sidecar.jsonl \
  --sidecar-manifest-source <A_OUT>/sidecar/control/sidecar_manifest.json \
  --seed-spec-json '{"source_kind":"analysis_context","source_payload":{}}' \
  --rule-family ref_ref \
  --budget-vector-json '{"D_max":128,"C_events":1048576,"S_bytes":1073741824,"rho_max":64.0}' \
  --closure-policy-json '{"allow_bounded":true,"allow_degraded":true,"frontier_ref_limit":4096}'
```

4. 重复执行至少 3 次 evidence 导出，复用同一 sidecar，记录重复导出的 `scan_count`、`seek_count`、`window_span_total`、`sidecar_lookup_count`、`sidecar_bytes`、`runtime_seconds`、`peak_rss_mb`。
5. 打开并校验证据包：

```bash
cd realization
PYTHONPATH=. python3 -m desktop.app.cli repro --package <A_OUT>/packages/run_001
PYTHONPATH=. python3 -m desktop.app.cli evidence-query --package <A_OUT>/packages/run_001 --kind proof
```

6. 生成 `A_control_plane_first/formal_summary_<platform>.json`。

还差哪些东西：

1. Linux 侧 A 组 formal summary、legacy 对照与 sidecar 复用批次已留档：`realization/docs/evidence_proof_archive_20260418/formal_10_4/A_control_plane_first/formal_summary_linux.json`。
2. 当前剩余是 Windows `A_control_plane_first/formal_summary_windows.json` 与对应环境摘要，以进入 patent-scope parity。

完成判据：

1. evidence 主路径没有发生全局重扫回退。
2. evidence 主路径相对对照路径物理扫描范围显著缩小。
3. `proof_digest` 可验证，`proof_hash` 一致性校验通过。
4. `formal_summary_linux.json` 与 `formal_summary_windows.json` 均为 `pass`。

```bash
python3 - <<'PY'
```

## 7. 工作项 WP-04：C 组降级可审计证明

| 注入类型 | 目标现象 | 预期 halt / blocker |
|---|---|---|

| 循环膨胀 | cycle guard 触发 | `CYCLE_INFLATION` |
| 段损坏或缺失 | window read 或 package control 出错 | 最小合法 degraded 包或明确拒绝 |
| I/O 守卫 | 读取保护触发 | degraded blocker 可定位 |

2. 对每类注入执行 evidence export，并设置允许降级：

```bash
cd realization
PYTHONPATH=. python3 -m desktop.app.cli export-evidence \
  --input <TRACE_1GB_OR_TARGET_CASE> \
  --output-dir <C_OUT>/packages/sidecar_mismatch \
  --embodiment-mode mode_b \
  --sidecar-source <BROKEN_SIDECAR_JSONL> \
  --sidecar-manifest-source <BROKEN_SIDECAR_MANIFEST_JSON> \
  --seed-spec-json '{"source_kind":"analysis_context","source_payload":{}}' \
  --rule-family ref_ref \
  --budget-vector-json '{"D_max":128,"C_events":1048576,"S_bytes":1073741824,"rho_max":64.0}' \
  --closure-policy-json '{"allow_bounded":true,"allow_degraded":true,"frontier_ref_limit":4096}'
```

3. 检查 degraded 包必备对象：

```bash
test -f <PACKAGE>/control/proof_digest.json
test -f <PACKAGE>/control/frontier_snapshot.json
test -f <PACKAGE>/control/sidecar_manifest.json
```

4. 打开 degraded 包：

