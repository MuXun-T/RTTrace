# P7.2 Claim Boundary

The acquired artifacts are licensed public FreeRTOS traces generated by the upstream repository's RV64 simulator. Zephyr and Zephelin are provenance audits only. All source records set `hardware_validation=false`.

This phase supports only the statement: licensed public FreeRTOS simulator traces were acquired with frozen provenance; Zephyr reproducible-simulator and Zephelin Renode sources were source-audited but produced no local artifact. It does not support diagnosis accuracy, root-cause correctness, general RTOS support, SOTA, performance, proof correctness, evidence closure, semantic replay, replay pass, or real-hardware validation.

Upstream documentation of a priority-inversion demo describes a workload scenario only. It is not independent ground truth and is not an accuracy result.
