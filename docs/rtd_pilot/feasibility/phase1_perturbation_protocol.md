# Phase 1 perturbation protocol

Build `BASE`, `GPIO_ONLY`, `GPIO_UART`, and `GPIO_UART_RECORDER` as separate FreeRTOS ELFs. The CMake mapping makes GPIO, UART, and recorder pulse compilation explicit; `TASK_SMOKE`, `MUTEX_SMOKE`, `IRQ_SMOKE`, and `COMBINED_SMOKE` independently enable their behavior. Compare real DSLogic/UART-derived summary inputs using `analyze_perturbation.py`: timer period, P95, ISR duration, execution window, UART drops, trace drops, and overflow count relative to BASE. `GPIO_ONLY` derives its CH1 rising-edge timer values with `analyze_clock.py --calibration-column CH1` and has no UART alignment result. Every input must contain every metric. A finite number is an observed value; `null` means the selected compiled variant does not expose that metric and is not zero. `phase1-perturbation-v2` labels each output as `observed`, `not_observable`, `baseline_not_observable`, or `baseline_zero`; a relative value appears only when both sides were observed and the baseline is nonzero. No synthetic data, hypothesis test, or statistical-significance claim is allowed.
